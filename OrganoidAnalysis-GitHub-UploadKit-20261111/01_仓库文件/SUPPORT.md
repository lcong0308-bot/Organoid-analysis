# 使用支持与反馈

请先查看 [使用指南](README.md) 和 [演示记录](docs/DEMO_RUN.md)。本仓库用于软件说明、版本发布和问题反馈，不包含应用源代码。

普通问题可在本仓库 Issues 中提交，选择“问题反馈”或“功能建议”。请提供版本、Windows 版本、操作步骤、期望结果和实际结果。可以附去除个人信息的截图及获准公开的最小示例。

不要公开上传密码、账户数据库、访问令牌、患者资料或未获授权的实验图片。涉及账号获取、账号停用或到期，请联系实际向你提供软件的维护人员；本文不提供默认账号或密码。
